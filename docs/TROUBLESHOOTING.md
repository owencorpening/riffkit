# Troubleshooting Guide

## Common Issues

* Stems are missing: confirm Demucs completed successfully and that the output folder contains `vocals.wav`, `drums.wav`, `bass.wav`, and `other.wav`.
* Lyrics do not appear: confirm the project has a track named exactly `Lyrics`, and that the transcription JSON matches the expected format.
* REAPER scripts do nothing: make sure you loaded the correct Lua script in REAPER and that the project has the required track names.
