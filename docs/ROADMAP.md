# riffkit Roadmap

## Purpose

`riffkit` is a music workflow system for REAPER. Its public focus is helping small groups turn a few songs into something they can rehearse, learn, and perform with less friction.

## Core Use Case

The clearest current use case is a church band:

1. A set of songs is delivered a few days before a service.
2. Each player needs to learn their own part.
3. Lyrics may need to be shown on a large TV or monitor.
4. The finished output needs to be reusable for rehearsal and service playback.

## Near-Term Goals

* Make stem separation and project setup reliable and predictable.
* Make part-learning easy by muting individual stems.
* Make lyric import and lyric display straightforward.
* Keep the REAPER scripts organized and easy to run.
* Avoid adding features that do not help with actual music workflows.

## What This Is Not

* Not a general-purpose DAW replacement
* Not a commercial SaaS product
* Not a support-heavy consumer app
* Not the same project as `reaper-react-bridge`

## Longer-Term Direction

* Support more repeatable set-prep workflows
* Improve handoff quality so projects can be reused with minimal cleanup
* Add only the music-adjacent tools that directly reduce rehearsal or performance friction
